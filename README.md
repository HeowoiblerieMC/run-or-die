# 🔴 RUN FOR LIVE

### RESTORE. RUN. ESCAPE.

**A first-person 3D escape game built with Three.js.**

The facility is locked.  
Three terminals remain offline.  
Something is searching for you.

## THE MISSION

```text
FIND 3 TERMINALS
        ↓
RESTORE THE FACILITY
        ↓
AVOID THE PURSUER
        ↓
UNLOCK THE EXIT
        ↓
ESCAPE ALIVE
```

You have **10 minutes**.

Running helps you escape, but makes you easier to detect.  
Sneaking keeps you quiet, but the pursuer is always moving.

---

## CONTROLS

```text
W A S D     Move
Mouse       Look around
W + R       Sprint
Shift       Sneak
E           Interact
Esc         Pause
```

---

## FEATURES

- First-person 3D exploration
- Pursuer patrol and chase AI
- Sprint and stamina system
- Sneaking and detection mechanics
- Terminal restoration objectives
- Escape gate and match timer
- Atmospheric research facility
